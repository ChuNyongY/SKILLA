# 파일 정리·PDF 열기 통합 스킬 파일럿

최종 갱신: 2026-10-14

## 증거 묶음

`tools/bundle_skill_study.py`는 둘 이상의 관측 파일과 근거 폴더를 입력받아 다음을 검증한다.

- 각 관측의 참가자·작업·반복·조건·성공 여부와 근거 JSON 내부 값 일치
- 관측에 저장된 `outcome_evidence_sha256`과 실제 파일 SHA-256 일치
- 소스 사이에 동일한 참가자·작업·반복·조건 셀 중복 없음
- 각 소스 폴더의 근거 파일 집합이 관측을 빠짐없이 정확히 포함
- 각 대응 블록에 SK0~SK3가 모두 있고 블록 안의 모델·도구·초기 상태가 동일

검증된 근거는 새 출력 폴더에 배타적으로 복사한다. manifest에는 원본 절대경로를 넣지 않고 소스 관측
해시, 복사된 근거 해시, 작업 ID, 통합 관측·보고서 해시만 기록한다.

실제 자기완결형 묶음은 `output/combined-skill-study-pilot-20261014`에 있다. 파일 정리와 PDF 열기
각 1블록, 총 8개 관측과 8개 근거를 포함한다. 모든 근거·관측·보고서 해시가 다시 일치했고 manifest에
workspace 절대경로가 없음을 확인했다.

## 통합 기술통계

| 조건 | 성공 | 평균 시간 | 평균 NIM 호출 | 평균 token | 평균 사용자 개입 |
|---|---:|---:|---:|---:|---:|
| SK0 스킬 없음 | 1/2 | 23,061.5 ms | 2.0 | 3,435.5 | 0.0 |
| SK1 저장 지침 | 1/2 | 38,943.5 ms | 3.0 | 5,998.0 | 0.0 |
| SK2 초기 스킬 | 2/2 | 17,036.0 ms | 1.5 | 2,377.0 | 1.0 |
| SK3 개정 스킬 | 2/2 | 13,678.0 ms | 1.5 | 2,482.5 | 1.0 |

SK3와 SK0·SK1의 성공률 차이는 각각 +0.5이고 SK3와 SK2의 차이는 0이다. 정확 McNemar 검정과
Holm 보정값은 세 비교 모두 1.0이다.

## 해석 한계

이는 하나의 복합 과제가 아니라 난이도와 도구 표면이 다른 두 작업을 조건별 기술통계로 합친 것이다.
파일 정리에서는 SK0·SK1이 실패했지만 한 단계 PDF 열기에서는 네 조건이 모두 성공했다. 따라서 현재
근거는 스킬 효과가 작업 복잡도에 따라 달라질 가능성을 보여줄 뿐이다. 작업마다 1블록이고 참가자도
하나이므로 통계적 우월성이나 일반 사용자 성능을 주장하지 않는다.
