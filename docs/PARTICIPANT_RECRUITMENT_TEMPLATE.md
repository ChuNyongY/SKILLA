작성일: 2026-10-17

> 소속 학교에 연구윤리 절차의 적용 여부를 확인한다.

## 연구 목적

Windows 반복 작업을 수행할 때 다음 네 방식의 작업 성공률과 소요 비용을 비교합니다.

1. 스킬 없음
2. 일반 저장 지침 사용
3. 최초 검증 스킬 사용
4. 실행 결과를 반영한 개정 스킬 사용

스킬은 작업 순서·판단 기준·확인 방법을 담은 재사용 절차입니다.

## 참가자가 하는 일

- 복원할 수 있는 연구용 Windows 환경에서 파일 정리·PDF 열기·폴더 확인 등의 반복 작업을 수행합니다.
- 같은 작업을 여러 조건에서 수행합니다. 조건 순서는 학습과 피로 영향을 줄이도록 균형화합니다.
- 실제 개인 파일과 계정은 사용하지 않습니다.
- 마이크, 스피커 청취 평가, Windows Hello는 이 실험에서 사용하지 않습니다.

## 수집하는 값

- 무작위 참가자 ID, 실험 조건, 작업과 반복 번호
- 성공 여부와 실행 시간
- 대형 언어 모델 호출 수와 입력·출 토큰 수
- 사용자 추가 개입 횟수와 계산 가능한 실행 비용
- 모델, 도구, 초기 상태와 결과 근거의 SHA-256 해시

분석 자료에는 이름, 학번, 이메일, 음성, 화면 녹화, 발화 원문, 실제 파일 경로와 계정 정보를 넣지 않습니다.

## 참가자의 권리

참가자는 이유를 말하지 않고 언제든 중단하거나 동의를 철회할 수 있으며, 이로 인한 불이익은 없습니다.
