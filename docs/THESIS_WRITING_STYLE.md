# 논문 작성 기준

SKILLA 논문과 발표 자료의 문장은 `CUBERAG_문종건_1.hwpx`의 서술 방식을 기준으로 작성한다.

## 문장 구성

- 연구 대상, 조건, 측정값과 결과를 먼저 쓴다.
- 한 문장에는 하나의 판단만 담고, 긴 수식어를 겹치지 않는다.
- 전문용어는 처음 나올 때 한국어 이름, 영문 이름, 약어 순서로 설명한다.
- “혁신적”, “압도적”, “완벽한”, “획기적”처럼 측정값으로 확인하지 않은 표현은 쓰지 않는다.
- 결과는 평균, 표본 수, 차이, 신뢰구간과 p값을 함께 제시한다.
- 통계적으로 유의하지 않은 결과를 효과가 입증된 것처럼 쓰지 않는다.
- 구현 사실, 실험 결과, 연구자의 해석과 후속 과제를 서로 구분한다.

## 문단 순서

1. 이 절에서 확인하려는 내용을 한 문장으로 제시한다.
2. 사용한 입력, 조건과 고정 설정을 설명한다.
3. 표나 그림의 수치를 문장으로 읽어 준다.
4. 수치가 의미하는 범위와 반례를 함께 설명한다.
5. 자료로 판단할 수 없는 내용은 제한점이나 후속 실험으로 남긴다.

## 피할 표현

- “본 시스템은 다양한 기능을 제공한다”처럼 대상이 분명하지 않은 문장
- “이를 통해 효율성을 극대화하였다”처럼 비교값이 없는 결론
- 같은 결과를 요약, 핵심, 시사점이라는 이름으로 반복하는 구성
- 모든 문단을 “본 연구는”, “또한”, “따라서”로 시작하는 일정한 문장 형태
- 실제로 측정하지 않은 사용자 편의성, 안전성 또는 일반적 성능 주장

## 명칭

- skill은 처음에 `스킬(skill)`로 쓰고 이후에는 `스킬`로 쓴다.
- Large Language Model은 `대형 언어 모델(Large Language Model, LLM)`로 처음 설명한다.
- harness는 `실행 하네스(harness)`로 쓰고, 실행·권한 확인·결과 검증을 묶은 구조라고 설명한다.
- SK0~SK3은 처음 등장할 때 각 조건의 뜻을 표로 제시한다.
