# Whisper large-v3-turbo 적용 확인

## 적용한 구성

- 설정: `config/product_host.json`의 `stt_manifest`
- 모델: `dropbox-dash/faster-whisper-large-v3-turbo`
- 고정 배포본: `0a363e9161cbc7ed1431c9597a8ceaf0c4f78fcf`
- 실행: faster-whisper, CPU, int8, 한국어, beam_size 5
- 신뢰도 경계: 구간 `avg_logprob >= -0.8`, `no_speech_prob <= 0.6`
- 설치: 프로젝트 루트에서 `.venv\Scripts\python.exe -m tools.prepare_turbo_stt`
- 파일 크기와 SHA-256 검증을 통과한 로컬 모델만 사용
- 실행 중인 이전 프로세스에는 적용되지 않으므로 SKILLA를 종료 후 다시 실행

## 수행한 확인

2026-11-05 개발 PC에서 저장된 Supertonic 3 합성 음성을 16 kHz 단일 채널로 변환해 입력했다

- 기준 문장: 스킬라입니다. 요청한 작업을 마쳤어요.
- 인식 문장: 스킬라입니다. 요청한 작업을 마쳤어요.
- 음성 길이: 3.371초
- 모델 로딩: 11.039초
- 추론: 5.729초
- 원기록: `output/stt_turbo_smoke.json`

신뢰도 경계를 추가한 뒤 같은 파일을 운영 어댑터로 다시 실행해 같은 문장을 인식했다
모델 로딩 7.323초, 추론 5.028초였으며 원기록은
`output/stt_turbo_confidence_guard_smoke.json`이다. 낮은 평균 로그확률, 높은 무음 확률,
NaN 값은 모두 발화를 폐기하는 자동 시험을 통과했다

호출어의 임의 한 글자 편집거리 허용은 제거했다. `스킬라`, `스킬라야`, 실제 인식 보정용
`스킬나`만 허용하고 `스킬`, `스키라`는 호출어로 보지 않는 시험을 통과했다

이 수치는 합성 음성 한 문장의 실행 확인이다. 실제 사용자 발음, 소음, 거리별 정확도나
이전 small 모델 대비 개선율을 측정한 결과가 아니다. CPU에서 실시간보다 느렸으므로
마이크 연속 입력의 지연·유실 여부는 별도로 확인해야 한다

추가로 GPU(float16) 실행을 시험했으나 `cublas64_12.dll`이 없어 추론에 실패했다
GPU 장치 감지만으로 가속 실행 성공을 판단하지 않았고, 현재 설정은 검증한 CPU 경로를 유지한다
가속에 필요한 구성은 [faster-whisper 공식 설치 안내](https://github.com/SYSTRAN/faster-whisper#gpu)를 따른다

## 실제 사용 확인 순서

1. SKILLA를 재시작하고 선택한 마이크 장치를 확인
2. 말할 때 REACTOR STATUS 원의 크기와 선 두께가 변하는지 확인
3. 조용한 환경에서 “스킬라, 시스템 정보 확인해 줘”를 말하고 인식 문장 확인
4. “취소”와 “현재 작업 중지”를 별도로 확인
5. 잘못 인식한 문장, 명령 종료부터 화면 표시까지 걸린 시간, 실행 여부를 함께 기록
6. 같은 문장을 거리·배경 소음을 바꿔 반복하고 실패도 기록

파형 반응은 마이크 입력 크기를 뜻한다. 문장 인식이나 명령 실행 성공을 뜻하지 않는다
등록·실행 전 확인이 필요한 작업은 기존 승인 절차를 유지한다
