# 스킬 검색 조사 처리 개선 파일럿

최종 갱신: 2026-10-14

## 목적과 변경

운영 검색기가 한국어 조사가 붙은 단어를 놓치거나 한 글자 토큰 때문에 관련 없는 스킬을 같은 점수로
만드는 문제를 확인했다. 검색 중 LLM·네트워크·외부 형태소 분석기는 사용하지 않았다.

- 한 글자 요청 토큰은 느슨한 단어 점수에서 제외한다.
- `음량을 → 음량`, `브라우저에서 → 브라우저`처럼 조사를 제거한 결과가 해당 스킬의 등록 어휘와
  정확히 같을 때만 그 어휘를 인정한다.
- 호출 문구 완전 일치 10,000점과 제목 일치 1,000점 우선순위는 바꾸지 않았다.
- 최상위 동점은 계속 `AMBIGUOUS`로 처리하며 어느 스킬도 실행하지 않는다.

## 변경 전 자료 고정

개선 코드를 작성하기 전에 `evaluation/skill_search_holdout_cases.json`의 25개 문장을 고정했다.
SHA-256은 `8dd0bc9e090efbaf3e3f72a9f3e3f4a041a5770f92ffcc31eae02ce3d14721fd`다. 기존 개발자료의 문장을
복사하지 않았으며 스킬별 자연어 긍정 요청 15건, 스킬 간 혼동 요청 5건, 무관 요청 5건으로 구성했다.

## 결과

| 자료 | 규칙 | 정답 | 거짓 양성 | 거짓 음성 | 잘못 선택 | 모호 | 정확도 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 개발 22건 | 변경 전 | 18 | 0 | 1 | 0 | 3 | 81.8% |
| 개발 22건 | 변경 후 | 19 | 0 | 1 | 0 | 2 | 86.4% |
| 보류 25건 | 변경 전 | 14 | 0 | 4 | 2 | 5 | 56.0% |
| 보류 25건 | 변경 후 | 21 | 0 | 1 | 1 | 2 | 84.0% |

변경 전 보류 결과는 `output/skill-search-holdout-baseline-20261014`, 변경 후 결과는
`output/skill-search-holdout-improved-20261014`에 있다. 두 manifest가 가리키는 cases SHA-256은
동일하며, 두 실행 모두 별도 VERIFIED 스킬 7개와 `skill_uses=0`을 기록했다.

남은 네 실패는 브라우저 표현 미검출 1건, 잘못된 시스템 스킬 선택 1건, 모호 판정 2건이다. 이 보류
자료의 결과는 이미 확인했으므로 다음 검색 변경을 이 자료에 맞춰 조정하지 않는다. 다음 개선은 새 자료를
먼저 고정하거나 실제 사용자 표현을 수집한 뒤 별도 평가한다.

## 해석 한계

이 결과는 개발자가 작성한 소규모 한국어 문장에 대한 검색 경로 파일럿이다. 실제 사용자 모집단의
성능, 전체 Windows 작업 성공률, 스킬 방식의 통계적 우월성을 증명하지 않는다. 거짓 양성 0건도
25개 무관 요청 안에서 관찰된 값일 뿐 일반적인 0% 오검출률이라는 뜻이 아니다.
