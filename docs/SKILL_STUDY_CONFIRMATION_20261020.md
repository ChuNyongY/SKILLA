# JAVIS 스킬 재사용 독립 확인 실험 사전계획

고정일: 2026-10-20 (결과 확인 전)

## 목적

완성된 JAVIS 실행기에서 스킬 없음(SK0), 일반 저장 지침(SK1), 최초 구조화 스킬(SK2),
실패 기록을 반영한 개정 스킬(SK3)을 같은 Windows 작업과 같은 초기 상태에서 비교한다.
기존 32블록 개발자 파일럿과 실행일·식별자·난수 seed를 분리한 확인 실험이다.

## 연구 질문

1. SK2와 SK3는 SK0·SK1보다 반복 작업 성공률을 높이는가?
2. SK3는 SK0·SK1·SK2보다 실행 시간, LLM 호출 수와 토큰 사용량을 줄이는가?
3. 작업이 단순할 때에는 스킬의 이점이 사라지거나 비용이 늘어나는 반례가 나타나는가?

성능 향상을 전제로 하지 않는다. 성공률과 비용이 나빠진 결과도 그대로 포함한다.

## 고정 조건

- 실행 묶음 식별자: `developer10`
- 고정 seed: `2026102001`
- 작업: 파일 정리, PDF 열기, 폴더 목록, 확장자 정리, Explorer 폴더 열기
- 반복: 작업별 3블록
- 조건: 블록마다 SK0, SK1, SK2, SK3를 각각 정확히 한 번 실행
- 전체 계획: 15개 완전 대응 블록, 60개 관측
- 모델: 각 runner에 고정된 동일 NIM 모델과 동일 생성 설정
- 순서: 고정 seed로 만든 균형 순서표
- 초기 상태: 조건마다 새 격리 fixture를 만들고 SHA-256 일치를 확인
- 성공 판정: LLM 자기 보고가 아니라 파일 위치·해시·창 상태 등의 독립 판정

## 측정값

- 성공 여부와 Wilson 95% 신뢰구간
- 요청부터 독립 검증 종료까지의 실행 시간
- LLM 호출 수와 입력·출력 토큰 합계
- 사용자 확인 횟수
- 모델 설정·도구 표면·초기 상태·결과 근거 SHA-256

## 수집·제외 규칙

- append-only 원장에 예정된 다음 셀만 기록한다.
- 실패와 예산 초과도 제외하지 않는다.
- 네 조건 중 하나라도 누락·중복된 블록, 조건 간 모델·설정·도구·초기 상태 해시가 다른 블록은
  분석기가 전체 입력을 거부한다.
- 근거 파일의 실제 SHA-256과 관측의 근거 SHA-256이 다르면 해당 묶음을 결과로 사용하지 않는다.
- 중단 후에는 같은 출력 폴더와 인자로 재실행하여 원장의 정확한 다음 셀부터 재개한다.

## 분석

- 조건별 성공률, Wilson 95% 신뢰구간과 평균 시간·호출·토큰·확인 횟수를 보고한다.
- SK3와 SK0·SK1·SK2의 성공 여부를 exact McNemar 검정으로 대응 비교한다.
- 세 p값은 Holm 방법으로 보정한다.
- 이 자료는 단일 개발 PC의 자체 확인 실험이다. 실제 참가자 연구나 일반 사용자 전체의 성능으로
  확대 해석하지 않는다.
