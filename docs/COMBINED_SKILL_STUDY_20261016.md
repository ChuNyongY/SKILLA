# SK0~SK3 다섯 작업 32블록 개발자 파일럿

최종 갱신: 2026-10-16

## 범위

이 결과는 파일 정리, hash-pinned PDF 열기, 읽기 전용 폴더 목록, 확장자별 파일 정리와 Explorer
폴더 열기 다섯 종류의 Windows 반복작업을 비교한 개발자 파일럿이다. 완전 대응 32블록,
128관측과 128개 결과 근거를 포함한다. `participant_id`는 사람 참가자가 아니라 익명 개발자 실행
묶음 식별자다.

각 블록은 SK0 스킬 없음, SK1 일반 저장 지침, SK2 구조화된 최초 스킬, SK3 실패 기록을 반영한
개정 스킬을 정확히 한 번씩 포함한다. 조건별로 모델 ID·모델 설정·도구 표면·초기 상태가 같지 않으면
분석기가 블록을 거부한다. 실패 관측도 제외하지 않았다.

추가 15블록은 결과 확인 전에 `developer09`, seed `2026101609`, 다섯 작업 각각 3회로 고정했다.
특정 작업에서 유의성을 만들기 위한 선택 수집이 아니며 append-only 원장으로 수집했다.

| SK1 저장 지침 | 24/32 | 75.00% | 25,177.78 ms | 2.219 | 3,949.88 | 0.406 |
| SK2 최초 스킬 | 30/32 | 93.75% | 26,666.91 ms | 2.25 | 3,953.41 | 0.844 |
| SK3 개정 스킬 | 32/32 | 100.00% | 20,281.50 ms | 1.75 | 2,927.78 | 1.000 |

SK3는 이 묶음에서 SK0보다 성공률이 18.75%p 높고 평균 시간 26.77%, 호출 22.22%, 토큰
24.81%가 적었다. SK1과 비교하면 성공률 +25.00%p, 시간 -19.45%, 호출 -21.13%, 토큰
-25.88%였다. SK2와 비교하면 성공률 +6.25%p, 시간 -23.94%, 호출 -22.22%, 토큰
-25.94%였다. 이는 이 개발자 묶음의 기술통계이며 일반적 성능 우월성을 뜻하지 않는다.

Explorer는 네 조건의 성공률이 같아 스킬이 성공률을 높이지 않는 반례다. 성공률 차이는 주로 여러
단계의 파일 이동 작업에서 나타났다.

## 통계 해석

SK3와 각 기준 조건의 같은 블록 성공 여부를 정확 McNemar 검정으로 비교하고 세 비교를 Holm
방식으로 보정했다.

| 비교 | 성공률 차이 | 불일치 쌍: 기준 실패·SK3 성공 | 반대 불일치 | 원 p값 | Holm 보정 p값 |
|---|---:|---:|---:|---:|---:|
| SK3 대 SK0 | +18.75%p | 6 | 0 | 0.03125 | 0.06250 |
| SK3 대 SK1 | +25.00%p | 8 | 0 | 0.0078125 | 0.0234375 |
| SK3 대 SK2 | +6.25%p | 2 | 0 | 0.50000 | 0.50000 |

SK3 대 SK1만 이 묶음에서 Holm 보정 p값이 0.05보다 작다. SK0와 SK2 비교는 보정 뒤 유의하지
않다. 개발자 반복 실행, 작업 이질성, 동일 개발 환경과 실제 사용자 부재 때문에 이 결과를 다른
사용자나 일반 Windows 작업에 대한 SK3 우월성으로 확대하지 않는다.

## 무결성 검증

- 12개 원본 source의 관측과 128개 evidence JSON을 배타 복사한 자기완결형 묶음이다.
- bundler가 각 evidence의 SHA-256과 참가자·작업·반복·조건·성공 여부를 관측과 대조했다.
- 각 완전 블록의 모델 설정·도구 표면·초기 상태 동일성을 분석기가 확인했다.
- 완료된 다섯 새 runner를 같은 인자로 재실행했을 때 ledger·observations·report 15개 파일의
  SHA-256이 모두 그대로였고 NIM 작업 셀을 다시 수행하지 않았다.
- 통합 observations와 report의 실제 SHA-256이 manifest 기록과 일치한다.
- 묶음에서 `nvapi-` 접두사와 Windows 절대경로 검색 결과는 각각 0건이다.
- observations SHA-256은
  `1b6962e57c9f3207cd7b78485610e641a61db0fbc1229a70a97a8c907701f75a`다.
- report SHA-256은
  `cb5aafa28900a712259ddbdbc2cb919385e24dda46d34140d04536b361d576b4`다.
- manifest SHA-256은
  `ed99f41a9b56e04cc0514e8e6485806785da0ad52b74912df1e01ed1641663ee`다.

자기완결형 근거는 `output/combined-skill-study-20261016-32blocks`에 있다. 모델 설정 기록이
잘못됐던 최초 폴더 목록 자료는 계속 무효 보관하며 이 묶음에 포함하지 않았다.

## 한계

- 실제 참가자 연구나 독립 사용자 표본이 아니다.
- 한 개발 PC와 제한된 다섯 작업의 반복 결과다.
- 단순 작업에서는 스킬 검색·구조화가 성공률 이득을 만들지 않았다.
