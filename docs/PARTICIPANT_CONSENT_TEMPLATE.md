## 연구 안내

이 연구는 Windows 반복 작업에서 스킬을 사용하지 않는 방식, 일반 저장 지침, 최초 검증 스킬,
개정 스킬을 비교합니다. 참가자는 복원할 수 있는 연구용 파일과 격리 환경에서 미리 정한 작업을
수행합니다.

- 예상 소요 시간: [확정 필요]
- 보상과 지급 조건: [확정 필요]
- 자료 보관 기간·위치·접근자·폐기 방법: [확정 필요]
- 연구자·지도교수 문의처: [확정 필요]
- 연구윤리 확인 결과와 승인 번호(해당하는 경우): [확정 필요]

## 수집하는 정보

- 무작위 참가자 ID, 조건·작업·반복 번호
- 성공 여부, 실행 시간, 대형 언어 모델 호출 수, 입력·출력 토큰
- 사용자 개입 횟수와 계산 가능한 실행 비용
- 모델·도구·초기 상태·결과 근거의 SHA-256 해시

분석 파일에는 이름, 학번, 이메일, 발화 원문, 음성, 화면 녹화, 실제 파일 경로와 계정 정보를 넣지 않습니다.
마이크, 스피커 청취 평가, Windows Hello는 이 실험에서 사용하지 않습니다.

## 중단과 철회

- 이유를 말하지 않고 언제든 중단하거나 동의를 철회할 수 있습니다.
- 중단·철회로 인한 불이익은 없습니다.
- 철회 전에 수집된 자료와 이미 완전히 익명화된 집계값의 처리 방법은 다음과 같습니다: [확정 필요]
- 철회 절차는 `PARTICIPANT_WITHDRAWAL_GUIDE.md`의 안내를 따릅니다.
