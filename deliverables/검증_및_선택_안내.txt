SKILLA 졸업논문·포스터 최종 산출물 검증 안내

1. 졸업논문
- 형식: 한컴오피스에서 열 수 있는 HWPX
- 구성: 서론, 이론적 배경, 시스템 설계, 프로그램 구현, 실험, 결론의 6장 구조
- 양식 반영: 제공된 2026 졸업논문보고서 양식의 제목·장·절·본문·목차·그림·표·참고문헌 스타일 적용
- 포함 자료: 시스템 실행 흐름, 스킬 구조, 실험 설계 그림 3개와 표 9개
- 내용 기준: 실제 구현 모델, 실제 컴퓨터 환경, 자동 시험 결과, 별도 실험 결과를 구분하여 작성
- 확인 결과: 문서 내부 구조 손상 없음, 필수 스타일 누락 없음, 한컴오피스 2022 열기 확인

2. 포스터 공통 사항
- 규격: A1 세로형 594 × 841 mm
- 공통 내용: 문제와 연구 목적, 기존 방식과 SKILLA 비교, 실행 흐름, 구체적 예시, UI 화면, 사용 모델, 하네스 역할, 실험 환경과 평가 결과
- UI 사진마다 화면의 역할을 짧은 설명으로 표시
- 실제 구현 화면을 사용하고 대기·계획·실행·검증·스킬 관리의 순서를 구분
- 모든 안에서 글자와 그림의 슬라이드 경계 넘침 검사 통과

3. 포스터 안별 차이
- 안1 균형형: 연구 문제, 시스템, UI, 실험 결과를 고르게 보여 주는 제출용 구성
- 안2 UI 시연형: 실제 사용 화면을 가장 크게 보여 주는 발표용 구성. UI 확인이 중요할 때 권장
- 안3 시스템 설명형: 하네스와 스킬 재사용 구조를 크게 보여 주는 설명 중심 구성

4. 제출 전 직접 입력할 사항
- 논문 표지의 학과, 학번, 성명, 지도교수 등 개인 정보
- 학교가 지정한 정확한 제출 연월
- 포스터 상단의 소속과 발표자 정보
